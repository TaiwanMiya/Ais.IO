版本 (v3.0)
功能：
	1. 基本
	✔ 開啟檔案
	✔ 儲存檔案
	✔ 另存檔案

        2. 游標與選取
        ✔ 單一選取
        ✔ 多段選取（Ctrl + 點擊）
        ✔ Shift 延伸選取
        ✔ Ctrl+A 全選

        3. 快捷鍵
        ✔ Ctrl+Home → 開頭
        ✔ Ctrl+End → 結尾
        ✔ Shift+Home / End
        ✔ Shift+PageUp / PageDown
        ✔ Ctrl+Shift+Home / End

        4. 編輯
        ✔ Hex 編輯（高 / 低 nibble）
        ✔ ASCII 編輯
        ✔ Backspace（刪前一 byte、選取刪除選取 bytes）
        ✔ Delete（刪當前 byte、選取刪除選取 bytes）
        ✔ Insert（插入 1 byte）
	✔ Hex 複製
	✔ Hex 貼上（可插入、可覆蓋）

        5. 搜尋 / 導航
        ✔ Find / Find Next / Find Prev
        ✔ Goto Offset
        ✔ 搜尋 / Goto 失敗時 LineEdit 紅色閃爍
        ✔ 搜尋成功時 Hex 區黃色高亮

        6. Undo / Redo
        ✔ Replace / Insert / Delete 皆可 undo

	7. 解釋器
	✔ 二進制 (8位元)
        ✔ Int8
        ✔ UInt8
        ✔ Int16
        ✔ UInt16
        ✔ Int24
        ✔ UInt24
        ✔ Int32
        ✔ UInt32
        ✔ Int64
        ✔ UInt64
        ✔ LEB128
        ✔ ULEB128
        ✔ AnsiChar / char8_t / ASCII
        ✔ WideChar / char16_t
        ✔ UTF-8 程式點
        ✔ Half (Float16)
        ✔ Single (Float32)
        ✔ Double (Float64)
        ✔ OLETIME
        ✔ FILETIME
        ✔ DOS 日期
        ✔ DOS 時間
        ✔ DOS 時間 & 日期
        ✔ time_t (32位元)
        ✔ time_t (64位元)
        ✔ GUID
        ✔ 反組譯 (x86-16)
        ✔ 反組譯 (x86-32)
        ✔ 反組譯 (x86-64)

	8. 差異比對
	✔ Diff Open / Diff Close
	✔ Diff Find / Diff Find Next / Diff Find Prev
	✔ 找到差異時 Hex 區綠色高亮


類別結構：
        ┌───────────────┐
        │  ChunksLite   │  ← 原始檔案（只讀、不修改）
        └───────▲───────┘
                │ read()
        ┌───────┴───────┐
        │  OverlayMap   │  ← 所有修改（insert / delete / overwrite）
        │  (piece table)│
        └───────▲───────┘
                │ read()
        ┌───────┴───────┐
        │   HexView     │  ← 游標、選取、undo/redo、UI、輸入
        └───────────────┘
